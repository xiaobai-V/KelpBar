# 07_Pipe -- 匿名管道

## 模块职责

学习匿名管道（pipe）实现父子进程间通信。包含两个演示程序：单向管道（父写子读）和双向管道（双管道实现父子双向通信）。

## 入口与启动

本模块包含 2 个独立可执行文件：

| 可执行文件 | 源文件 | 说明 |
|-----------|--------|------|
| `main` | `main.c` | 单向管道：父进程写入，子进程读取 |
| `two_pipe` | `two_pipe.c` | 双向管道：使用两条管道实现父子双向通信 |

### 编译与运行

```bash
mkdir -p build && cd build
cmake ..
make
./main       # 单向管道演示
./two_pipe   # 双向管道演示
```

## 对外接口

本模块为独立演示程序，无对外接口。

### 演示的系统调用

| 函数 | 头文件 | 说明 |
|------|--------|------|
| `pipe()` | `<unistd.h>` | 创建匿名管道，`pipefd[0]` 读端，`pipefd[1]` 写端 |
| `fork()` | `<unistd.h>` | 创建子进程 |
| `read()` | `<unistd.h>` | 从管道读端读取数据 |
| `write()` | `<unistd.h>` | 向管道写端写入数据 |
| `close()` | `<unistd.h>` | 关闭管道端口 |
| `wait()` | `<sys/wait.h>` | 等待子进程 |

## 数据模型

### 单向管道数据流（main.c）

```
父进程 --[write pipefd[1]]--> 管道 --[read pipefd[0]]--> 子进程
```

### 双向管道数据流（two_pipe.c）

```
父进程 --[write pipefd1[1]]--> 管道1 --[read pipefd1[0]]--> 子进程
子进程 --[write pipefd2[1]]--> 管道2 --[read pipefd2[0]]--> 父进程
```

## 测试与质量

- `main` 预期输出：
  ```
  我是父进程..., 有一个子进程...
  父进程发送了...个数据
  我是子进程..., 我的父进程是...

  Child exited with status 0
  ```
- `two_pipe` 预期输出：
  ```
  Parent received from child: Hello, Parent!
  Child received from parent: Hello, Child!
  ```
  （输出顺序可能因调度而异）
- 无自动化测试

## 常见问题 (FAQ)

**Q: 为什么单向通信也要 close 未使用的端口？**
A: 管道的读端在写端全部关闭后 `read()` 才会返回 0（EOF）。如果不关闭父进程的读端，子进程的 `read()` 可能一直阻塞。

**Q: 为什么双向通信需要两条管道？**
A: 匿名管道是半双工的（单向数据流），要实现双向通信必须创建两条管道。
